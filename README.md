# AeroRozum — Junction 2026

Thermal drone investigation environment for agent research.

The implementation is developed on reviewable branches:

- [`codex/paired-physics-sensors`](https://github.com/Yegmina/Junction_2026/tree/codex/paired-physics-sensors): research platform, native Gazebo flight, paired physics-derived thermal and RGB, dashboard and tests.
- [`codex/gpu-agent-evaluation`](https://github.com/Yegmina/Junction_2026/tree/codex/gpu-agent-evaluation): stacked on the sensor branch; four-A100 Gemma decision checks, image-blind controls and progress reporting. This is the latest integrated development branch.

Thermal fields and camera composition are experimental and not field-validated mine detection. Keys, recordings, datasets, model weights and private run logs are excluded from Git.
