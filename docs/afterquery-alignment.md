# AfterQuery alignment audit — 2026-11-14

Source read in a real browser: https://junction2026.com/challenges/afterquery-break-the-agent
This page labels itself community-made information; the partner starter kit and
supplied harness remain the authority for integration details.

The setting fits, but execution has over-prioritized optional perception training
and physical qualification relative to the core agent-environment evaluation.

The linked rubric: reproducible frontier/reference gap 30 points; meaningful
decision difficulty 30; reward integrity 25; reproducibility/craft 15. Smaller-model
training is an optional stretch/tiebreaker. Described judging runs: reference,
three agent runs, do-nothing, stop-early, then exploit attempts. Supplied stack:
Harbor/OpenCode over MCP.

## Existing evidence

- Campaign environment, time/flight budgets, candidate reports, hidden evaluator
  state and observability checks exist in `aerorozum/environment.py`.
- `aerorozum/mcp_server.py` exposes a public tool allow-list with images.
- Tests exercise duplicate claims, invalid evidence, action overrides, truth
  separation and budgets. Unit tests alone do not establish reward robustness.
- Two saved Gemini development campaigns completed in 7 and 8 actions, seeds
  20261114/20261115. Both explicitly have `demo: true` and
  `research_accepted: false`; these do not establish the required benchmark.
- A complete verified Harbor/OpenCode judging bundle was not located.
- SFT/GRPO work measures perception, not long-horizon campaign decisions. The
  completed label-source controls did not improve true-positive recall.

## Priority correction

1. Freeze a playable, honestly scoped thermal-survey task. Make decisions about
   timing, inspections, revisits, resources, evidence merging and reporting matter.
   Required information must be available through public tools. Recorded views
   must not be presented as physically simulated counterfactual viewpoints.
2. Verify the supplied harness contract and provide one evaluation command. An
   MCP adapter alone does not prove Harbor/OpenCode compatibility.
3. Demonstrate a stronger reference policy or human trace using the same public
   information, tools and resource limits. Do not use a privileged truth oracle.
4. Run the reference, three frontier-agent runs, do-nothing and stop-early controls
   on frozen tasks. Save seeds, models, actions, observations, scores and replays.
5. Attack reward integrity: no-op, early stop, duplicate/report spam, stale
   evidence, repeated coverage and truth access. Good task completion must beat
   shortcuts. Explain the frontier agent's actual decision failures.
6. Lead the presentation with the benchmark, measured gap and failure analysis.
   Real footage, physics and optional Gemma training support that story.

The subsequent user instruction explicitly requested GPU use alongside Harbor
integration. Bounded perception experiments therefore run in parallel with the
primary benchmark work. They remain supporting evidence until evaluated in
the same closed-loop task. Existing bounded physics jobs continue without
solver expansion or relaxed quality gates. See the current
[integration evidence](submission-integration-progress.md); the earlier audit
above records the state before native Harbor trials existed.
