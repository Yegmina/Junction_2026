THE VERIFIER

Reward the investigation.

0.65 × retrieval F₂
+ 0.20 × region coverage
+ 0.15 × independent views

One-to-one matches penalize duplicate and unsupported claims. Positive claims in the new task need evidence at ≤4.5m; independent views need ≥1m horizontal separation. A report, airborne evidence, home return and budget compliance are required.

A separate simulator owns the authoritative ledger. Workspace file edits cannot rewrite its telemetry, captured images or target state.
